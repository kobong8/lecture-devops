# 자료 검색과 발표 복귀

## 사용 방법

- 포털·강의 상단 `자료 검색`, `Ctrl+K` 또는 macOS `⌘K`로 검색 창을 연다.
- 포털은 전체 강의, 강의 안에서는 현재 강의로 시작한다. 검색 범위를 바꾸어 전체 또는 다른 강의를 검색할 수 있다.
- Enter 또는 검색 버튼으로 실행한다. 한글 조합 중 Enter는 검색을 실행하지 않는다.
- 제목·본문·표·코드·이미지 대체 설명을 검색한다. 대소문자·전각 문자·반복 공백을 정규화하고, 여러 단어는 모두 포함된 장을 찾는다. 제목 일치가 많은 결과를 우선 표시한다.
- 결과에 강의명·장 번호·제목·일치 문장과 강조를 표시한다. 결과를 선택하면 해당 장으로 이동한다. 검색창은 Esc 또는 닫기로 종료한다.
- 검색 결과에서 `발표 위치로 복귀`로 원래 강의의 원래 장으로 돌아간다. 검색을 다시 해도 최초 발표 위치를 유지한다. 브라우저의 sessionStorage를 사용할 수 있으면 원래 장의 스크롤 위치와 집중 레이아웃도 복원한다.
- 전체 화면 권한은 문서 이동 후 자동으로 다시 요청하지 않는다. 집중 레이아웃 복원과 브라우저 전체 화면은 구분한다.
- `링크 복사`는 검색 복귀용 쿼리를 제외한 현재 장 주소를 복사한다. 권한 거절 시 주소 입력란을 띄워 수동 복사할 수 있다.

## 구조와 배포

`build_search.py`가 8개 강의의 158개 슬라이드를 HTMLParser로 읽어 `assets/search-index.json`을 생성한다. Python 기본 라이브러리만 사용하며 HTML 안의 JavaScript는 실행하지 않는다. 이미지 픽셀의 글자나 별도 모달의 숨겨진 설명에는 OCR/추가 색인을 적용하지 않는다.

`assets/search-core.mjs`는 정규화·검색·발췌·복귀 주소 검증을, `lecture-search.js`는 대화상자·결과·복귀·복사를 담당한다. 검색 자료는 최초 검색 시에만 읽으며 실패 시 검색 버튼으로 재시도할 수 있다. 외부 검색 서비스나 서버 API를 사용하지 않는다. 프로젝트 하위 경로를 기준으로 자산과 링크를 계산하므로 GitHub Pages에서도 사용할 수 있다.

`scripts/start.ps1`에서 서버 시작 전에 색인을 갱신한다. 서버가 켜진 상태에서 HTML을 수정했다면 `python build_search.py`를 다시 실행하고 브라우저를 새로고침한다. 배포 전 `python build_search.py --check`가 통과해야 하며 생성 JSON을 함께 배포한다. JSON이 없거나 오래되면 전체 검색이 실패하거나 예전 내용을 표시한다.

복귀 링크는 같은 저장소의 `lecture_note/*.html#장-id`만 허용한다. 검색어는 저장하지 않는다. sessionStorage 접근이 차단돼도 URL로 원래 장 복귀는 제공하지만 스크롤·집중 상태 복원은 생략한다. 다른 탭에서 연 결과도 복귀 링크는 유지되며 스크롤 상태는 보장하지 않는다. 원래 장에서 검색하지 않고 포털에서 검색한 경우 복귀 버튼을 표시하지 않는다.

## 검증 (2026-10-18)

- Python 검사 5개 통과: 기존 발표 연결, 전체 강의 색인, 갱신 누락, 중첩 HTML/표/코드/alt 추출 및 script/style 제외.
- Node 검사 4개 통과: 정규화, AND·강의 필터·제목 우선순위, 발췌·특수문자, 하위 경로·외부 복귀 주소 차단.
- 검색 색인 158개 장 생성 및 `--check` 통과.
- JavaScript 문법 검사 완료.
- FastAPI HTTP 확인: 포털·강의 페이지·검색 JSON·JS·MJS·CSS 모두 200, 모듈 MIME 확인.
- 실제 브라우저 상호작용/시각 검수는 미실행. 기존 환경의 브라우저 연결 및 Playwright 부재에 따른 제한이다.

```powershell
python -m unittest discover -s tests -p "test_*.py"
node --test tests/search.test.mjs  # 선택적 개발 검사; 실행/배포에는 Node 불필요
python build_search.py --check
```

수동 확인: 한글 조합·결과 0건·강의 범위·키보드 포커스·모바일·집중 모드 중 검색·다른 강의 검색 후 재검색 및 최초 위치 복귀·복사 거절·저장소 차단·하위 경로 배포. 검색창에서 T/E/C/방향키가 배경 테마·게임·연락처·발표를 조작하지 않아야 한다.
