# Kobong 발표 템플릿 적용

`kobong-site-template`의 발표형 디자인을 기존 강의 HTML에 맞게 적용했다. 원고를 축약 예제로 바꾸거나 새로운 데이터 형식으로 변환하지 않고 기존 8개 강의의 158개 슬라이드를 유지한다.

## 적용 파일

- `assets/kobong-presentation.css`: SAIF 색상·목차·카드·강조 문구·상하단 탐색과 반응형 스타일. 기존 주제별 CSS 다음에 로드한다.
- `assets/kobong-presentation.js`: 기존 `goSlide`와 연결하는 공통 발표 제어. 원본 본문을 다시 작성하지 않는다.
- `index.html`: 강의 포털에 같은 색상과 카드 스타일 적용.
- `lecture_note/*.html`: 공통 자산 연결, 기존 중복 단축키 제거, 밝은 테마를 기본값으로 변경. 저장한 테마 선택은 유지한다.

본문의 마지막 직접 자식이 기존 `highlight-box` 또는 `info-box`일 때만 어두운 KEY TAKEAWAY 양식으로 표시한다. 원문을 요약하거나 새로운 결론을 생성하지 않는다. 기존 이미지 확대·텍스트 모달·코드 복사·주제별 다이어그램은 유지한다. 코드 복사 실패 시 수동 복사 안내를 추가했다.

## 발표 조작

| 입력 | 동작 |
| --- | --- |
| ← / →, PageUp / PageDown, Space | 이전/다음 슬라이드 |
| Home / End | 처음/마지막 슬라이드 |
| F / Esc | 집중 모드 전환/종료 |
| T | 밝은/어두운 테마 전환 |
| 모바일 목차 | 선택한 장으로 이동 |

위/아래 방향키는 긴 슬라이드의 기본 스크롤을 위해 유지한다. 입력란·선택 목록·편집 영역·조합키와 모달에 발표 단축키를 적용하지 않는다. 버튼/링크/목차 항목에서 Space는 해당 요소의 동작을 유지한다. 전체 화면 요청이 거절되어도 집중 레이아웃은 사용할 수 있다.

기존 강의 URL을 유지하고 `#slide-2` 같은 개별 슬라이드 주소를 추가했다. 번호는 1부터 시작하며, 이미 ID가 있는 장은 그 ID를 사용한다. 순서 기반 자동 ID는 장 삽입 시 의미가 바뀔 수 있으므로 지속 공유할 장에는 고유한 HTML `id`를 지정하는 것을 권장한다.

## 실행과 배포

기존 FastAPI 실행 방식을 유지한다. 프로젝트 폴더에서 `python app.py`를 실행하고 `http://127.0.0.1:8000`을 연다. npm 설치나 빌드는 없다. 정적 배포 시 새 CSS/JS도 기존 `assets/`와 함께 배포한다.

## 검증 기록 (2026-10-18)

- 8개 강의의 `<main>` 원문을 Git HEAD와 비교: 158개 슬라이드 모두 동일.
- 모든 강의의 인라인 JavaScript 및 새 공통 JavaScript 문법 검사 통과.
- HTML 연결과 슬라이드 구조 검사: `python -m unittest discover -s tests -p "test_presentation.py"`.
- 브라우저 시각·상호작용 검수는 미실행: 현재 연결된 브라우저가 없고 Python Playwright 패키지가 설치되어 있지 않음.

수동 확인: PC/390px 모바일에서 목차·다음/이전·긴 장 스크롤·테마·F/Esc·직접 링크 새로고침·코드 복사·이미지/텍스트 확대를 확인한다. DevOps 순환 도식과 Kubernetes 스토리지 도식은 별도로 확인한다. 외부 이미지와 글꼴은 기존 정책을 유지하므로 네트워크 환경에 따라 로딩 결과가 달라질 수 있다.
